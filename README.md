# OOP E-commerce Project
Учебный проект на Python, реализующий базовую модель интернет-магазина с применением объектно-ориентированного программирования. Включает классы Product и Category, работу с приватными атрибутами, геттерами/сеттерами, методами класса, обработку дубликатов, и модульное тестирование.
## Содержимое
project/
├── src/
│   ├── product.py       # Класс Product
│   └── category.py      # Класс Category
├── tests/
│   ├── test_product.py  # Тесты для Product
│   └── test_category.py # Тесты для Category
├── .gitignore
├── pyproject.toml       # Конфигурация проекта (poetry)
├── README.md            # Этот файл

## Функциональность
Класс Product:
Создание товара с названием, ценой, количеством и описанием.

Приватный атрибут price с геттером/сеттером:

Защита от установки нулевой или отрицательной цены.

Подтверждение понижения цены пользователем.

Класс-метод new_product():

Создает новый товар или обновляет существующий (если имя совпадает).

Объединяет количество и выбирает наивысшую цену.

Класс Category:
Хранение списка товаров (приватный).

Геттер products, возвращающий список товаров в виде форматированных строк.

from src.category import Category
